# Library Management System

A simple Library Management System written in Java that allows users to manage books with functionalities such as adding, saving, and loading library data using serialization. The code follows object-oriented principles, includes exception handling, and uses an abstract storage structure for better extensibility.

## Features

- Add books to the library
- Save library data to a file using Serializable
- Load library data from file
- Clear separation of concerns using packages
- Structured exception handling with custom exceptions
- Extensible design with abstract storage class

## Technologies

- Java 8+
- Object Serialization (ObjectOutputStream / ObjectInputStream)
- Custom Exception Handling
